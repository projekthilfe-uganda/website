Das Wichtigste zuerst

Speichern heißt: für alle sichtbar.
Nach dem Klick auf Save steht Ihre Änderung nach etwa 5 Minuten im Internet.

Keine Angst vor Fehlern.
Jeder alte Stand wird aufbewahrt. Der technische Ansprechpartner kann alles zurückholen.

Die Knöpfe im Editor sind auf Englisch. In dieser Anleitung sehen sie so aus: Save.

Anmelden

  1. Öffnen Sie projekthilfe-uganda.de/admin.
  2. Klicken Sie auf Log in.
  3. Geben Sie Ihre E-Mail und Ihr Passwort ein.

Noch kein Konto? Fragen Sie den technischen Ansprechpartner. Sie bekommen dann eine Einladung per E-Mail.

Zuerst das Menü öffnen.
Das Menü ist am Anfang zu. Klicken Sie oben links auf das Symbol ☰.

Im Menü gibt es vier Bereiche:

AktuellesNeuigkeiten und Rundbriefe

Media ManagerAlle Bilder und PDFs (siehe Mediathek)

Welche Seite heißt wie?

Achtung: Manche Namen stehen zweimal in der Liste.
Zum Beispiel verein. Einmal ist es ein Ordner, einmal eine Seite.

  • Sie wollen die Seite „Unser Verein“ ändern?
    Klicken Sie auf die Seite verein.
  • Sie wollen eine Unterseite des Hauptmenüpunkts „Unser Verein“ ändern, z. B. „Kontakt“?
    Öffnen Sie den Ordner verein. Darin finden Sie die Seite kontakt.

Ordner erkennen Sie am Ordner-Symbol. Genauso ist es bei projekte und helfen.

Links steht der Menüpunkt auf der Website. Rechts steht der Name in Pages.

verein › kontakt heißt: erst den Ordner verein öffnen, dann kontakt anklicken.

Bausteine

Jede Seite besteht aus Bausteinen. Ein Baustein ist ein Stück der Seite, zum Beispiel ein Text oder eine Bildergalerie.

Auf der Website stehen die Bausteine untereinander. Die Reihenfolge ist dieselbe wie im Editor.

Was kann ich mit Bausteinen machen?

  • Hinzufügen: Auf + klicken. Der neue Baustein kommt ganz nach unten.
  • Verschieben: Links am Baustein festhalten und an die neue Stelle ziehen.
  • Löschen: Auf den Papierkorb klicken. Erst mit Save ist er wirklich weg.

Article

Überschrift und Text. Der normale Baustein.

  • h1 große, h2 mittlere, h3 kleine Überschrift. Alle sind freiwillig.
  • Body: der Text

Article with Picture

Text mit einem großen Bild daneben.

  • Picture: das Bild
  • Layout: pic-right = Bild rechts, pic-left = Bild links. Muss ausgefüllt sein.

Picture Slider

Große, wechselnde Bilder ganz oben auf der Seite.

  • Steht immer ganz oben, egal wo er in der Liste steht.
  • Nur einen pro Seite.
  • Breite Bilder (Querformat) nehmen.

Teaser Block

Kacheln mit Bild und kurzem Text. Sie führen zu anderen Seiten.

  • Jede Kachel: Text mit Link und ein Picture
  • Farben wechseln von allein.

Gallery

Viele kleine Bilder. Ein Klick macht sie groß.

  • Gallery Title: Überschrift
  • Alt Tag: kurz beschreiben, was auf dem Bild ist. Wichtig für blinde Menschen.

Link List

Eine Liste mit Links, z. B. zu Videos.

  • Link: die Adresse, mit https://
  • Text: was man auf der Website liest
  • open in new tab: Link öffnet sich in einem neuen Fenster

Impressum und Datenschutz haben keine Bausteine. Dort gibt es nur ein großes Textfeld (Body).

Text ändern

  1. Öffnen Sie das Menü ☰ und klicken Sie auf Pages.
  2. Klicken Sie auf die Seite, die Sie ändern möchten. Welche Seite wie heißt, steht unter Wo finde ich was?
  3. Rechts sehen Sie die Bausteine der Seite. Klicken Sie auf einen Baustein, um ihn zu öffnen.
  4. Ändern Sie den Text.
  5. Klicken Sie auf Save.
  6. Warten Sie 5 Minuten. Schauen Sie dann auf der Website nach.

Tipps

  • Öffnen Sie die Website in einem zweiten Fenster. Dann sehen Sie, welcher Text wo steht.
  • Text aus Word kopiert? Fügen Sie ihn so ein: Strg + Shift + V (Mac: ⌘ + Shift + V).
  • Link setzen: Wort markieren, auf das Ketten-Symbol klicken, Adresse einfügen.

Bild einfügen

Zuerst: Bild kleiner machen!
Handyfotos sind zu groß. Die Website wird sonst langsam.

  • Gehen Sie auf squoosh.app und ziehen Sie das Bild hinein.
  • Breite: 1200 Pixel (Bilder ganz oben: 1920).
  • Ziel: unter 500 KB.

Einfacher Dateiname: keine Leerzeichen, keine Umlaute.
Gut: schule-2025.jpg · Schlecht: Unsere Schüler (neu).JPG

Tipp: Laden Sie Bilder vorher in der Mediathek hoch. Dort können Sie sie in Ordner legen. So bleibt alles ordentlich.

  1. Klicken Sie auf das Bildfeld Picture. Die Mediathek geht auf.
  2. Öffnen Sie den Ordner mit Ihrem Bild.
    Neues Bild? Ziehen Sie es in das Fenster. Oder klicken Sie auf Upload.
  3. Klicken Sie das Bild an. Dann auf Insert.
  4. Klicken Sie auf Save.

PDF einfügen? Siehe Mediathek.

Neuigkeit schreiben

  1. Öffnen Sie das Menü ☰ und klicken Sie auf Aktuelles.
  2. Klicken Sie oben rechts auf Create New und dann auf News Article.
  3. Filename: Datum und Thema, ohne Leerzeichen. Zum Beispiel 2025-11-rundbrief.
  4. Füllen Sie Title (Überschrift) und Date (Datum) aus.
  5. Bei News Blocks auf + klicken und Article wählen. Schreiben Sie Ihren Text.
  6. Klicken Sie auf Save.

Die neueste Neuigkeit steht automatisch ganz oben.

Seite verstecken

Ganz oben im Formular gibt es das Kästchen Hidden (draft).

Haken anSeite ist auf der Website unsichtbar.
Haken ausSeite ist auf der Website sichtbar.

Danach immer Save klicken.

Praktisch für: einen Text, der noch nicht fertig ist. Oder eine alte Aktion, die Sie nicht löschen wollen.

Bitte beachten

  • Startseite, Impressum und Datenschutz nie verstecken. Das ist Pflicht per Gesetz.
  • Versteckt heißt nicht geheim. Schreiben Sie nichts Vertrauliches hinein.
  • Steht die Seite im Menü? Dann nehmen Sie sie zuerst aus dem Menü. Sonst führt der Menüpunkt ins Leere.

Neue Seite anlegen

Am einfachsten: Kopieren Sie eine ähnliche Seite. Klicken Sie dazu in der Liste neben der Seite auf Duplicate.

  1. Öffnen Sie das Menü ☰, klicken Sie auf Pages und öffnen Sie den passenden Ordner, z. B. projekte.
  2. Klicken Sie auf Create New und dann auf Block Page.
  3. Filename: ein kurzes Wort, klein, ohne Leerzeichen. Zum Beispiel brunnenbau.
  4. Setzen Sie den Haken bei Hidden (draft), solange die Seite nicht fertig ist.
  5. Fügen Sie mit + Bausteine hinzu, z. B. Article.
  6. Fertig? Haken weg und Save klicken.

Die neue Seite steht nicht von allein im Menü. Tragen Sie sie selbst ein, siehe Menü ändern.

Seiten bitte nicht umbenennen. Sonst funktionieren alte Links nicht mehr.

Menü ändern

Das Menü oben auf der Website hat Hauptpunkte (z. B. „Unser Verein“) und Unterpunkte (z. B. „Kontakt“).

  1. Öffnen Sie das Menü ☰, klicken Sie auf Menu und dann auf menu.
  2. Unter Menu Items stehen die Hauptpunkte. Klicken Sie auf einen Hauptpunkt, um ihn zu öffnen.
  3. Die Unterpunkte stehen darin bei Submenu.
  4. Ändern Sie, was Sie möchten, und klicken Sie auf Save.
NameText im Menü, z. B. „Kontakt“
URLAdresse der Seite. verein › kontakt wird zu /verein/kontakt.
IconNur für das Haus-Symbol der Startseite. Sonst leer lassen.

Hinzufügen, verschieben und löschen geht wie bei den Bausteinen. Die Reihenfolge im Editor ist die Reihenfolge auf der Website.

Prüfen Sie nach dem Speichern auf der Website: Führt der neue Menüpunkt zur richtigen Seite?

Mediathek

In der Mediathek liegen alle Bilder und PDFs der Website. Im Editor heißt sie Media Manager.

  1. Öffnen Sie das Menü ☰ und klicken Sie auf Media Manager.
  2. Sie sehen Ordner und Dateien. Klicken Sie auf einen Ordner, um ihn zu öffnen.

Bilder hochladen und ordnen

Am besten hier hochladen, nicht im Bildfeld.
Dann legen Sie Bilder gleich in den richtigen Ordner. So finden Sie sie später schnell wieder.

  1. Öffnen Sie den passenden Ordner.
    Noch kein Ordner da? Klicken Sie auf New Folder und geben Sie einen Namen ein, z. B. 2025-rundbrief.
  2. Ziehen Sie die Bilder in das Fenster. Oder klicken Sie auf Upload.
  3. Fertig. Jetzt können Sie die Bilder im Bildfeld auswählen (siehe Bild einfügen).

Ordnernamen wie Dateinamen: einfach, ohne Leerzeichen und Umlaute.

PDF hochladen

Genauso wie Bilder. Dann im Text einen Link auf die PDF setzen:

Wo liegt die PDF?Link
Direkt in der Mediathek/uploads/dateiname.pdf
In einem Ordner der Mediathek/uploads/ordnername/dateiname.pdf

Bilder und Ordner bitte nicht löschen. Sie werden vielleicht noch auf anderen Seiten gebraucht.

Hilfe, es klappt nicht

Meine Änderung ist nicht zu sehen

Warten Sie 10 Minuten. Laden Sie die Seite dann neu: Strg + F5 (Mac: ⌘ + Shift + R).
Immer noch nicht? Sagen Sie dem technischen Ansprechpartner, welche Seite Sie wann geändert haben.

Ich habe aus Versehen etwas gelöscht

Noch nicht gespeichert? Laden Sie die Seite einfach neu. Nichts ist passiert.
Schon gespeichert? Der technische Ansprechpartner holt es zurück.

Ein Bild fehlt auf der Website

Meist ist der Dateiname schuld. Geben Sie dem Bild einen einfachen Namen und laden Sie es neu hoch.

Das Datum ist einen Tag zu früh

Das ist ein bekannter Fehler. Wählen Sie einfach einen Tag später und speichern Sie.

Eine Seite ist verschwunden

Ist der Haken bei Hidden (draft) gesetzt? Dann Haken weg und Save klicken.

Das Anmeldefenster geht nicht auf

Ihr Browser blockiert das Fenster. Oben in der Adresszeile erscheint ein Hinweis. Klicken Sie auf „Pop-ups erlauben“.

Jemand anderes arbeitet an derselben Seite

Wer zuletzt speichert, überschreibt die Änderungen der anderen Person. Bitte sprechen Sie sich ab.
